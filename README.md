# Next.js Starter MCP - Landing Page

Landing page for the Next.js Starter MCP kit: a Bash generator and a local stdio MCP server for creating Next.js apps. The kit is a paid product (one-time payment, commercial license); this site only describes it.

## Overview

This project creates a modern, professional landing page to showcase the Next.js Starter MCP tool, featuring:

- **Modern Design**: Built with Next.js 14+ and Tailwind CSS
- **Accurate content**: Install steps and template list mirror the product README on `main` of `Bendako/next-starter-script`
- **Legal pages**: `/privacy` and `/terms` are drafts with `[PLACEHOLDERS]` to complete
- **Pricing**: placeholder section until checkout is live

## Tech Stack

- Next.js 14+ with App Router
- TypeScript
- Tailwind CSS
- Vercel deployment

## Development

```bash
# Install dependencies
npm ci

# Lint and build
npm run lint

# Run development server
npm run dev

# Build for production
npm run build
```

## Project Structure

Next.js App Router app: pages live in `src/app`, sections in `src/components`.
